# Leyka POS Cambios y Vales

Extiende el flujo de devolución por ticket de Odoo 19 sin reemplazar su control de inventario.

- Reconoce el importe realmente pagado, incluidos descuentos.
- Admite cambio inmediato, vale o reembolso excepcional.
- Exige un titular simplificado para el vale.
- Registra condición y destino: venta, cuarentena, merma o garantía.
- Evita devolver más unidades que las compradas.
- Mantiene separados el vale y el reembolso de dinero.
